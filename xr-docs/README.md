# XR-CLAW Documentation 📖

XR-CLAW 使用文档中心。

## 目录结构

```
xr-docs/
├── getting-started/   # 快速上手指南
├── play-guide/        # 玩法指南（创意项目教程）
├── assembly/          # 硬件组装教程
├── api/               # API 参考文档
└── faq/               # 常见问题
```

## 文档规范

- 中英双语（Chinese primary, English translation follows）
- Markdown 格式
- 图片存放在同目录 `images/` 子目录
- 每个文档头部包含：标题、作者、最后更新日期、适用版本

### 文档模板

```markdown
# 文档标题 / Document Title

> 作者: XXX | 最后更新: YYYY-MM-DD | 适用版本: vX.X.X

## 中文说明

内容...

## English

Content...
```
